## Video Requirements
- Format: MP4
- Resolution: 1920x1080 or 1280x720
- Duration: 10-30 seconds (loop-friendly)
- File size: Under 5MB for fast loading
- No audio needed (will be muted)

## How to Add Videos
1. Download videos from recommended sources
2. Convert to MP4 if needed
3. Rename files according to this structure
4. Place in this directory
5. Videos will autoplay automatically on the services page
